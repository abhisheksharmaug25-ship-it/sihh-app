# SIH 2026 Submission Checklist

Before submitting the GitHub repository link, verify each item:

## Repository

- [ ] Repository is public and accessible to reviewers
- [ ] README.md has project info, problem statement, solution, features, tech stack, installation, and run steps
- [ ] Repository structure follows the SIH template (src, docs, assets, submission)
- [ ] LICENSE file present

## Content

- [ ] `docs/architecture.md` — architecture diagram and component description
- [ ] `assets/screenshots/` — key screenshots added
- [ ] `submission/PRESENTATION.md` — final PPT committed or linked
- [ ] `submission/DEMO.md` — demo video link (optional but recommended)

## Security

- [ ] No passwords, API keys, access tokens, or `.env` files with secrets committed
- [ ] `.env.example` contains placeholder values only
- [ ] Session secrets are long random values in production

## Deployment

- [ ] Live demo URL works 
- [ ] Register/login flow works on the deployed site
- [ ] Document upload works (Vercel Blob connected)

## Team

- [ ] Team details (names, roles, GitHub handles) added to README
